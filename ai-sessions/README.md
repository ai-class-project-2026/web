# AI 세션 기록

AI로 한 작업은 전부 여기 남긴다 (기획서 17.8 AI 사용 규칙). 파트마다 폴더가 따로 있다.

| 폴더 | 담당 |
|---|---|
| `part1/` | 파트 1 (아키텍처 + 일정 AI + 욕설 모델 학습 + 통합) |
| `part2/` | 파트 2 (웹 화면) |
| `part3/` | 파트 3 (욕설 데이터 + 평가) |
| `part4/` | 파트 4 (날짜 규칙 + 테스트 데이터 + 발표) |

## 처음 한 번만

```sh
git config ai.part part3   # 본인 파트 번호로
```

이것만 하면 이 레포에서 Claude Code를 쓸 때 자동으로 기록된다. 세션 하나가 파일 하나(`날짜_세션ID.md`)이고, 프롬프트마다 아래가 쌓인다.

* **프롬프트**: 보낸 내용 그대로
* **결과**: AI의 최종 답변
* **변경 사항**: 그 프롬프트 동안 바뀐 코드 diff (새로 만든 파일 포함)

설정 안 하면 `unknown/` 폴더에 쌓인다. 그 파일은 본인 폴더로 옮겨서 커밋한다.

## Claude Code가 아닌 도구 (ChatGPT 웹, Codex 등)

같은 폴더에 `날짜_도구_주제.md`(예: `2026-11-16_chatgpt_augment.md`)로 직접 붙여 넣는다.

````markdown
# AI 세션 2026-11-16 ChatGPT

- 파트: part3
- 도구: ChatGPT (모델 이름)

---

## 프롬프트

(보낸 내용 그대로)

### 결과

(AI 답변 그대로)

### 변경 사항

(바꾼 파일과 내용. 커밋 전에 `git diff`를 붙여 넣으면 된다)
````

## 규칙

* 로그는 코드와 같은 PR에 커밋한다. AI로 만든 코드인데 로그가 없으면 머지하지 않는다
* `.env`, API 키, 비밀번호, 실제 사용자 대화는 프롬프트에 넣지 않는다. 실수로 들어갔으면 커밋 전에 로그에서 지운다
* 테스트셋(파일럿, 실제, C, D)은 합성 데이터 생성이나 학습 프롬프트에 넣지 않는다
